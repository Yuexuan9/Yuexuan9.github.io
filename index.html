Projects

S1 Mobile Manipulation — From Relative Actions to Robot Deployment

I developed the data processing and inference pipeline for mobile manipulation on the S1 robot. I separated the mobile base’s (x, y, yaw) actions into a dedicated modality and converted absolute odometry targets into normalized SE(2) actions relative to the current base pose for policy training. During inference, I denormalized the predicted actions and composed them with the current odometry pose to recover absolute targets, then sent these targets to the base controller in the ODOM frame.

LM-X on Astribot S1 — Cloth Folding

I trained, deployed, and evaluated LM-X vision-language-action policies for cloth folding on Astribot S1. My work covered checkpoint comparison, failure analysis, and debugging the robot execution pipeline. Through model iterations incorporating Value-based progress estimation and deployment optimization, our final policy achieved 80% success (16/20) in the paper’s real-robot evaluation. This project connected model training with hands-on robot deployment and systematic evaluation.

π0-Based Manipulation on Qinglong — Aviation Connector and Parcel Sorting

I worked on applying π0-based vision-language-action models to the Qinglong humanoid robot, targeting industrial aviation connector sorting and parcel sorting scenarios for WAIC and WRC. My work included model training and evaluation, capability testing, and failure analysis to support model selection and iterative improvement. I also developed the inference pipeline and adapted it to the robot platform, connecting data collection with deployment on the physical robot.

Visual Affordance — Robotic Pick and Place Tasks

In this project, I explored the Visual Affordance method for visual robotic pick-and-place tasks. I implemented and trained a Visual Affordance model with manually labeled data and used rotated heightmaps, domain randomization, and self-supervision to improve the model’s performance. We aimed to improve the model’s grasp success rate on unseen objects.

Robot Design Project

During this project, I applied SolidWorks and Python to design and create a legged robot, covering conceptual design, detailed design, simulation and modeling, digital manufacturing, electronics, and sensor design. I used a 3D printer to print the robot body and optimized its gait in simulation and on hardware using Python.

Design Project — Smart Signs

Smart Signs addresses a common frustration for commuters: uncertainty about public transportation. Our team developed a solution that replaces static subway signs with dynamic screens that can be remotely updated in real time to reflect track maintenance and delays.

Through design thinking and collaboration, we identified an emerging human need and used new technology to create a solution with the potential to improve the daily commute.
